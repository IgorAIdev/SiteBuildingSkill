# Sport — вид витрины

Плотный спортивный магазин по образцу Gymshark (черты, не копия): узкий заголовок
прописными (Oswald), текст Inter, холодный нейтраль и почти чёрная марка, ритм «Плотный»,
углы «Crisp · pill», плоско, без теней. На главной вместо снимка героя — плакат: заголовок,
строка текста и путь в каталог; полка товаров стоит сразу под ним, так что первое окно
показывает и слова, и товар. Двери эффектов — снимок, имя под ним прописными.

```sh
npm run storefront -- --no-watch --variant sport --port 3022
```

Адрес — http://localhost:3022/en на том компьютере, где выполняется команда. На Windows —
`tools/start-sport-storefront.cmd`. Сохранить вид, выбранный в панели Look, в репозиторий:
`npm run storefront -- --variant sport --save-look`. Не используйте `--fresh`, чтобы просто
запустить сервер: он удаляет runtime-копию вида.

Бриф, замеры и чего не взято: [docs/design/четвёртая-витрина.md](../../../docs/design/четвёртая-витрина.md).
