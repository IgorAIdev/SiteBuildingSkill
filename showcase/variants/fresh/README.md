# Fresh — вид витрины

Живой wellness-бренд (черты Olipop, не копия): мягкая засечка Fraunces в заголовках,
DM Sans в тексте, тёплая кремовая бумага и одна насыщенная марка кобальта (в тёмной теме
светлее — по замеру контраста), углы «Round · pill», плоско, круглые кнопки со стрелкой,
ритм «Воздушный». Ряд эффектов лежит цветной плитой марки на всю ширину, слово магазина —
тёмной; имя эффекта — пилюля на снимке.

```sh
npm run storefront -- --no-watch --variant fresh --port 3023
```

Адрес — http://localhost:3023/en на том компьютере, где выполняется команда. На Windows —
`tools/start-fresh-storefront.cmd`. Сохранить вид, выбранный в панели Look, в репозиторий:
`npm run storefront -- --variant fresh --save-look`. Не используйте `--fresh`, чтобы просто
запустить сервер: он удаляет runtime-копию вида.

Бриф, замеры и чего не взято: [docs/design/четвёртая-витрина.md](../../../docs/design/четвёртая-витрина.md).
