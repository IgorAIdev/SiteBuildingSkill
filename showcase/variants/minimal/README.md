# Quiet graphite — второй вариант витрины

Современный минимализм: тёплый светлый фон, графитовые действия, Manrope, больше воздуха, небольшие скругления и карточки без рамок в покое. Главная показывает товар из существующей полки; категории — текстовыми ссылками. Дизайн-панель, каталог, товар, корзина и оформление используют общие компоненты.

Нужен Node.js 24. На Windows можно открыть двойным щелчком
`tools/start-minimal-storefront.cmd`; для первой витрины — `tools/start-storefront.cmd`.
Они переходят в нужную папку и запускают сервер. Оставьте окно открытым.

Или из корня клонированного **SiteBuildingSkill**:

```sh
npm run storefront -- --variant minimal --no-watch
```

После сообщения Ready откройте http://localhost:3021/en **на том компьютере, где выполняется команда**. Первый запуск ставит зависимости; оставьте терминал открытым. Остановка — Ctrl+C.

Первый вариант в другом терминале:

```sh
npm run storefront -- --no-watch --port 3020
```

Его адрес на том же компьютере: http://localhost:3020/en. Запуск в облачной среде не запускает сервер на ноутбуке и сам по себе не даёт внешнего адреса.

Варианты живут отдельно в `.storefront/` и `.storefront-minimal/`. Если порт занят, задайте `--port 3030`. Не используйте `--fresh`, чтобы просто запустить сервер: он удаляет runtime-копию выбранного варианта. Чтобы сохранить выбранный через Look вид минимальной витрины в репозиторий:

```sh
npm run storefront -- --variant minimal --save-look
```

Опубликованный вид записывается в эту папку; первая витрина не перезаписывается. Уже существующий runtime сохраняет собственный опубликованный вид при повторном запуске, как и раньше.

Каталог при запуске берётся из настроенного Vendure; часть содержания — образцы. Это вариант предпросмотра. Реальные заказы отдельно включаются конфигурацией магазина, а дизайн не подтверждает их готовность.
