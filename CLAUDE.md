# Правила вёрстки

Ядро: читается каждым запросом — только правила, по строке. Почему каждое
заведено — `docs/claude-full.md` (те же разделы) и журнал `docs/rules.md`
(И499). Процесс сайта — `skills/site-building/SKILL.md`; разбор правил —
свои скиллы: `craft` — экран, `palette` — цвет, `scale` — размер и
расстояние, `code` — код, `shop` — магазин, `seo-content` — тексты,
`stages` — когда что.

Код противоречит этому файлу — прав файл, код чинится, а не повторяется.
**Правило, у которого нет реализации, хуже отсутствующего правила.**

---

## Вёрстка: десять запретов

Разбор — скилл `craft`; в скобках — семьи проверок.

**1. `font-size` в пикселях запрещён** — размер из шкалы `--fs-*`; нужного
нет — правится шкала (`styles/scale.json` → `npm run scale`), не число на месте.

**2. Ритм — из шкалы, геометрия контрола — от его высоты.** Между вещами —
`--air-*` / `--pad-*` / `--gap-*` из `--sp-*`; `margin` — только ритм
(оптика меньше 8px — исключение); форма, тень, движение и состояния — роли
(`--r-ctrl`, `--sh-*`, `--press-t`, `--state-*`; И228, И229).

**3. Три брейкпоинта: `1080`, `820`, `560`** — только где меняется смысл
раскладки; ступенька размера на шве — дефект (`tools/seams.mjs`:
`breakpoint`, `deadSeam`, `seamStep`).

**4. У всего с `aspect-ratio` есть потолок** (`max-block-size`); кадр —
примитив `frame`.

**5. Число колонок вычисляется** — `repeat(auto-fit, minmax(...))`.

**6. Компонент меряет контейнер, а не окно** — `@container`
(`nodeWindow`, `sizeContain`, `fullVw`).

**7. Раскладка берётся из двенадцати примитивов** `styles/primitives.module.css`:
`stack`, `cluster`, `switcher`, `rail`, `prose`, `lede`, `pinned`, `sidebar`,
`grid`, `sheet`, `menu`, `frame`.

**8. Слой — по поведению:** модальное — `<dialog>` + `showModal()`,
немодальное — `popover`; номер слоя — только у висящего всегда (`--layer-*`).

**9. Приклеенное и открытое поверх помещается в окно:** колонка — `pinned`
(`stickyCap`); окно и шторка — `styles/pane.module.css`, шапка стоит, тело
прокручивается (И460); лента — в колонке сайта (`offColumn`, И598).

**10. Контрол живёт в одном месте:** знак — в файле знаков, устройство — в
своём модуле; блоки его берут, а не рисуют (`twiceDrawn`, `deadEffect`).

Раскладка не зависит ни от ширины, на которой её смотрели, ни от длины текста.

---

## Переносимость: одна вёрстка, любой движок

Три слоя: **общее** (CSS, токены, значки, разметка), **переходник** (данные
движка в ту же разметку, без решений о виде), **данные**. Компонент не ходит
в бекенд и не считает деньги (`npm run check:port`, И248).

---

## Что проверяется автоматически

Храповики: `check:css`, `check:craft`, `check:design`, `check:detect`,
`check:seo`; всё по порядку — `npm run check:all`. Отрисованные проверки —
только на сборке, не на сервере разработки. Днём — изменённые страницы;
полный прогон (`build`, `check:craft`, `sweep`, `check:engines` — «верно у
меня» не проверено, И630) — ночью и перед сдачей.

---

## Витрина: как править шаблон

Правится шаблон `templates/storefront/`, не копия `.storefront/`
(`npm run storefront`, порт 3020, И751); проверки — в `.storefront/` её
командами (И399); выбранный в панели вид — `npm run storefront -- --save-look`
в `showcase/`. Влитие в `main` выкатывает витрину-образец набора (И434).
Торговля — Vendure; образец — `SOURCE=sample`; ключи в репозиторий не идут.

## Этапы производства

## Правила работы

**Отвечать простыми словами** — по-русски, что сделано и что видно, без команд.

**Граница ответственности.** Как устроено и выглядит — моё, без вопросов.
Тексты, снимки, имена, реквизиты, состав блоков — заказчика; дефект
наполнения — строкой в ответе и в `docs/open.md`. Образцы в шаблоне — не дефект.

**SEO и GEO — с первого сценария** (И503); **описание — порядком, потом
перечнем** (И217).

**Дизайн делается дизайнерскими скиллами.** Любая правка вида — по порядку:

1. контекст — `impeccable context` (PRODUCT.md, DESIGN.md, бриф);
2. `impeccable critique` по `check:detect` и `check:design`; новое — `shape`;
3. референсы и замок — 3–5 живых магазинов, бриф `docs/design/` (И474);
4. пространственный тезис письменно — и одна вещь, которую запомнят;
5. `impeccable layout`, `typeset` и другие по находкам;
6. `impeccable polish` — каждое решение из референса, брифа или правила.

Где скилл спорит с набором — прав набор (И271, И300, И496).

**Сверка всего сайта — без просьбы** после пакета правок вида и перед сдачей
(скилл `stages`, И523).

**Работа показывается отрисованной** — правка влита, заказчик смотрит сам;
снимки в чат — только по его просьбе (И500).

**Готовое скачивается, а не рисуется** — образец из MIT-библиотек (HyperUI,
Flowbite, daisyUI, shadcn/ui); своё — только если готового нет (И643).

**Как у профессионалов** — решение сверено с источником и живым образцом
(`docs/references.md`; у нового правила — `Источник:`, И661).

**Присланный элемент — рисуется в `elements/`**, базовым, в трёх
состояниях, красками палитры.

**Выбор — глазами, а не списком.** Вопрос без показанного — переложенная работа.

**Панель настройки отделена от сайта** — снимается одной командой, только
словом заказчика (`check:look`, И277).

**Правка делается, а не обсуждается**; спросить — когда два прочтения ведут к
разной работе. **Строится ровно названное** — без вуалей и теней «для контраста».

**Делается только правильно — сразу:** сначала назван слой (краска →
палитра → роль; размер → шкала → роль; раскладка → примитив; контрол →
модуль; значение → данные); нет возможности — расширяется слой (И295).

**Опираясь на правило — приведи его текст**, а не пересказ.

**Урок — в свой раздел скилла-хозяина сразу, правило — в проверку**, с
дефектом, который его купил. Журнал `docs/rules.md` заморожен 10.10.2026 —
архив номеров И, на которые ссылаются код и скиллы; новых номеров нет.

**Ветка и вливание.** Ветка → PR → проверки → merge. Мелкие правки, особенно
названные заказчиком, вливаю сам; свои находки — тоже, но в отчёте
**полужирным, по пунктам 1. 2. 3.** (владелец 10.10.2026). Одна задача — один
PR (И500). Явное «не публиковать» соблюдаю. Минуты GitHub — деньги: всё
гоняется локально до пуша, CI — только вручную (AGENTS.md).
