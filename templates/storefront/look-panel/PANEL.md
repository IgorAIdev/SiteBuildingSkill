# Панель вида — правила и настройки

Панель физически отделена от сайта: весь каталог вариантов и весь расчёт —
здесь, в `look-panel/`; сайт хранит один опубликованный вид готовыми
значениями и панель не ввозит. Правило — `CLAUDE.md`, раздел «Панель
настройки физически отделена от сайта».

## Шаги

1. **Каталог.** Ставщик набора собирает `ui/catalog.json` из полного каталога
   набора его строителями и кладёт рядом копию движка палитры набора
   (`ui/engine/`, та же, что у мастерской): `node look-panel/scripts/build-catalog.mjs
   --from <набор>` (`npm run look:catalog -- --from <набор>`). Каждый вариант —
   значения свойств, которые сайт объявляет у себя (`lib/look-slots.json`).
   Собран каталог — опубликованный вид пересчитывается из своих имён этим
   каталогом (И352): решение заказчика — имена, значения из них выводит
   набор. Вырос каталог или движок (новая роль палитры, новая ось кнопки) —
   каждое свойство получает значение из ЕГО выбора, а не умолчание стилей
   другой палитры. Имена не трогаются; прежний файл при первой перемене —
   копией `lib/source/sample/look.before-refresh.json`; имя, которого в
   каталоге больше нет, не угадывается — группа держит прежние значения, и
   сборка называет его строкой «⚠ вид:». Что пересчитано — строкой отчёта
   (её передаёт и ставщик).
2. **Выбор.** Панель на витрине (`LOOK_PICKER=on`), вход — тонкая полоса
   «Look» у низа окна со своим местом (И354): видна с любого места любой
   страницы, страница держит под неё резерв нижней полосы (`--dock`), и
   ничего под полосой не прячется. В полосе одна цель — у её конца, под
   панелью: «Look», выбор словами (палитра · шрифт · ритм, «Draft», пока
   страница показывает черновик), «Open»; открытая панель стоит на полосе,
   и та же цель её закрывает («Close»). Открытая панель сама открывается и на следующей странице. Раздел —
   System или Admin, подраздел — строкой под ним. Щелчок по варианту сразу
   красит страницу и пишет черновик вида; черновой режим видит только этот
   браузер. Вариант — слово, выбранный — жирным и подчёркнут (пилюль нет:
   длинное имя в пилюлю не помещалось, И508). Подразделы Color, Type,
   Spacing, Shape и Buttons кончаются образцом «On the site» — кусок витрины
   ролями сайта, меняется вместе со страницей. Вариант, который с текущими не носится, погашен, и причина —
   одной строкой под группой. «Expand» в шапке панели разворачивает её:
   каждый вариант крупным образцом (ниже, «Развёрнутая панель»).
3. **Проверка.** `npm run check:choice -- '<скопированный выбор>'` (без
   аргумента — опубликованный вид): правило сайта по значениям и покрытие —
   вид даёт значение каждому свойству сайта, ни одно не берёт умолчание
   стилей (И353), затем
   `check:craft` на главной, первой полке и первом товаре основного языка,
   обе темы, все ширины. Вердикт словами: «ГОДИТСЯ» или «НЕ ГОДИТСЯ» с
   причинами.
4. **Публикация.** Кнопка «Publish»: черновик проверяется (шаг 3), шрифт
   скачивается в `public/fonts/` (страница покупателя к Google не ходит) и
   не записывается, если не умеет букв языков рынка (И769),
   вид пишется в опубликованный, кэш вида сбрасывается — без сборки. Стили
   сайта выпускаются из опубликованного вида при следующей сборке (И272).
5. **Снятие — только в магазине и только словом заказчика.**
   `npm run look:remove` ничего не удаляет: показывает, что уйдёт, — папку
   `look-panel/`, вход `app/look-panel/`, строку подключения в
   `components/Shell.tsx`, свои команды в `package.json`, флаг `LOOK_PICKER`,
   черновик, шрифты, которых опубликованный вид не носит, варианты шапки,
   карточки товара и главной, кроме выбранных. Снять: `npm run look:remove -- --yes` —
   сперва всё удаляемое, опубликованный вид и черновик копируются в соседнюю
   папку `<сайт>.look-backup-<ГГГГММДД-ЧЧмм>/` (в ней README — как вернуть),
   а если сайт в git — ставится метка `look-panel-before-remove-<время>`;
   затем снятие и выпуск стилей из опубликованного вида. `npm run check:look`
   доказывает снятие на копии рядом: сборка, тот же вид, ни чужих вариантов в
   отгружаемых стилях, ни следов панели.
6. **Возврат.** Из набора одной командой: `node install.mjs --look-panel
   <папка сайта>` — вернёт панель, все варианты шапки, карточки и главной из
   шаблона набора, флаг (выключенным: включить — `LOOK_PICKER=on` в `.env`) и
   команды, соберёт каталог; опубликованный вид сайта не тронет. Файл с
   метками, который магазин успел поправить после снятия, затирается только
   по слову `--force`. Ровно прежнее состояние — из папки копии (README).

Черновик пишет панель целиком: открытая панель держит выбор в памяти страницы и
при следующем нажатии переписывает весь `look.draft.json`. Правка вида на
сервере — через выбор в панели; правил черновик руками или скриптом — заказчику
сначала обновить страницу с панелью (F5), иначе его панель вернёт прежнее.

## Шаблон и магазин

Шаблон витрины — основа для многих магазинов, и в нём панель нужна всегда
(слово заказчика 24.09.2026: «в шаблоне панель удалять нельзя даже случайно,
потому что вложим туда много сил сейчас»). Поэтому снять её нельзя — без
ключа, который бы это перебил:

- в шаблоне набора (`templates/storefront`);
- в витрине шаблона — установке `node install.mjs --storefront <папка>`: на
  ней настраивается сам шаблон (демо `cbd-storefront-demo` — такая витрина);
- там, где у сайта нет записи ставщика о роли (`.site-kit-install.json`).

Снимается она только в МАГАЗИНЕ, построенном из шаблона: `node install.mjs
--storefront --shop <папка магазина>` пишет роль `shop`, и `look:remove` её
читает. Переустановка (`--force`) данные сайта не трогает: имена
опубликованного вида, черновик, `public/fonts/`, `.env` остаются как были
(И277). Значения опубликованного вида — выведенные из имён — сборка каталога
пересчитывает нынешним каталогом (И352, шаг 1), прежний файл — копией рядом.

угол — из Corners; формы (стрелка, шеврон, хвост) носит только главная
кнопка.

## Color: палитра из намерения

Строитель своей палитры — только на компьютере (слово заказчика
28.09.2026): на телефоне на его месте строка, выбор готовых наборов
остаётся; открытый строитель закрывается крестом, собранное остаётся в
черновике (И508).

Свою палитру заказчик строит не тремя красками, а намерением (И275):

- **Brand** — цвет марки: образец с выбором краски, код с логотипа, тон
  ползунком. Строитель держит тон и ищет ближайшую светлоту и насыщенность,
  при которой проходят все роли марки — надпись на главной кнопке, кольцо
  фокуса, отличие от скидки и наличия. Подвинул — показывает «ваш цвет →
  для кнопок» двумя образцами и одной строкой почему.
- **Paper** — Warm, Neutral или Cool, тон None или Light.
- **Ink** — сам: темнеет, пока текст не сдержит обещание эталона (Lc 90 для
  основного, WCAG для текста и органов); по желанию — с уходом в марку.
- **Dark** — выводится из тех же намерений.
- **Fine-tune exact colours** — свои коды бумаги, чернил и марки по темам;
  они тоже доводятся до замера.

Движок — копия `skills/site-building/assets/studio/engine/` набора в
`ui/engine/` (`fitPalette`, `roles`, `auditPalette`, `groundChecks` из
`tools/palette.mjs`); второй математики у панели нет. Восемь наборов — готовые
начала: «Build your own» переносит намерение набора в строитель. Вместо
списка ошибок — «Guaranteed»: текст читается на странице и карточках,
надписи кнопок и плашек читаются (и главная на тёмной полосе под рукой),
тихая кнопка видна на странице, карточках и тёмной полосе, шевроны хвоста
главной видны на каждом полу, у выключенной кнопки видна кромка, текст
героя читается на любом снимке, марка отличима от скидки и наличия, кольцо
фокуса видно, обе темы; числа (WCAG, APCA Lc, ΔE) — под раскрытием «The
numbers». Опубликованный вид хранит готовые значения и рядом — три краски
на тему и намерение, чтобы строитель открыл палитру снова.

### Краски кнопки — роли палитры

Кнопка своих красок не мешает (И295): её роли выпускает строитель палитры,
и «Guaranteed» показывает их замер тем же движком.

| роль | что | откуда |
| --- | --- | --- |
| `--pop` · `--on-pop` | главная: заливка и надпись | ступень 9 марки и знак на ней |
| `--quiet` | тихая: вуаль | чернила долей 8 % (в восьми битах экрана — 21/255), видна на каждом полу |
| `--pop-trail-near` · `--pop-trail-far` | шевроны хвоста главной | ступени марки рядом с заливкой, на стороне пола; дальний виден на каждом полу (APCA Lc ≥ 15) |
| `--edge-off` | кромка выключенной | ступень нейтрали, видная под прозрачностью выключенного |
| `--scrim-near` · `--scrim-far` | вуаль героя | самая тёмная нейтраль темы; доля — наименьшая, при которой текст героя держит 4.5 : 1 на белом снимке |

У ролей, идущих за полом, по две краски — для страницы и для тёмной полосы
(`-paper`, `-deck`); переназначает пол сайта.

## Развёрнутая панель

Слово заказчика 24.09.2026: «панель меню делай расширяемой, например чтоб
все кнопки показать» (И299).

1. «Expand» в шапке — панель до 1120 в ширину, справа, страница слева
   живая: панель немодальна, щелчок по варианту сразу красит страницу.
   Верх (разделы, подразделы) и низ (действия) стоят, прокручивается
   середина; высота — от экрана, как у узкой.
2. Каждый вариант — плитка: крупный образец на том, на чём он встанет, и
   подпись под ним. Кнопка — настоящая кнопка сайта (его же класс, снятый со
   страницы) на полу страницы и на тёмной полосе; палитра — карточка товара
   её красками; одежда карточки — карточка; остальное — крупный образец.
   Выбранная плитка — кольцо и галочка: заливка закрыла бы образец.
3. «Collapse» — обратно в 360. На телефоне развёрнутая — шторка во всю
   высоту окна, кнопки — в одну колонку, прочее — в две.
4. Ширина помнится за зрителем (`localStorage` этого браузера, ключ
   `look-panel-wide`): развернул однажды — так панель и откроется.

## Страница дизайн-системы

`/<язык>/design` показывает, панель выбирает. Правила страницы — по словам
заказчика 30.09–01.10.2026:

- **Переключателей на странице нет** — каждый выбор только в панели (кроме
  палитры, И572); переключатель на странице заказчик принял за поломку.
- **Каждый вариант — настоящий компонент сайта** с вариантом, переданным
  свойством, а не копия и не выбор панели (И605, И620); образец, которого сайт
  не носит, — сначала компонент сайта (И673).
- **Вкладка — ассортимент плитками**: образец, имя, одна строка о нём; без
  сводок, строк «где стоит на витрине» и строк замеров.
- **Карточки — одной рельсой, страницы и разделы — столбиком**; вариант — один
  раз, на полу страницы, без тёмной подложки.
- **Раскладка — для ноутбука**: на телефоне страницу не открывают.
