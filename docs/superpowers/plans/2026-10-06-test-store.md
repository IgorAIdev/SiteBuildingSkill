# Тестовая покупка в опубликованной витрине

Пользователь выбрал работу товаров, корзины, оформления и форм без списания
денег. Сценарий: добавить → изменить количество/удалить → контакт → доставка
→ тестовая оплата → подтверждение. Режим явно обозначен на странице.

1. Собрать каталог из экспортированных страниц: вариант, имя, цена, фото,
   адрес. Проверить все кнопки добавления; не подменять каталог другим.
2. Чистый движок в ресурсе скилла: целые суммы, ограничения количества,
   сохранение/восстановление, единый итог, тестовый заказ. Сначала unit-тесты.
3. Подключить движок к странице и панели корзины обоих дизайнов. Оформление
   использует существующие роли; поля проверяются, результаты показываются
   внутри страницы. Пароли/карты не сохраняются, данные наружу не отправляются.
4. Генератор подключает ресурсы и checkout-маршруты. Блокирующее alert
   удаляется только после подключения работающих обработчиков.
5. Браузер: добавление, счётчики, перезагрузка, удаление, валидация, заказ,
   формы и свайп. Опубликовать на прежний Site; изменения набора — в PR.
