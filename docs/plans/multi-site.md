# Одна витрина — много сайтов

Решение владельца 21.10.2026: «одна витрина конечно» — на вопрос «сто доменов —
сто сторфронтов?». Первый сайт — Бельгия (cbdbuy.be), второй — Хорватия
(cbdshop.hr, домен позже). Копия `apps/storefront4` магазина (Хорватия) стоит
нетронутой, пока Хорватия не переедет на общую витрину.

## Почему

Витрины магазина (`apps/storefront3` — cbdin.ro, `apps/storefront4` —
cbdshop.hr) — копии шаблона набора. Каждая правка набора переносится в каждую
копию руками, и копии расходятся (21.10.2026: файл групп знаков и карта товара
у копии уже были другими). При N доменах это N переносов на правку.

## Как у профессионалов

Многосайтовая витрина на Next.js — образец Vercel «Platforms» (multi-tenant):
прокладка (`proxy.ts`) узнаёт сайт по имени хоста и переписывает адрес на
внутренний сегмент `/[site]/…`; страницы собираются заранее на каждый сайт;
отличия сайтов — данные. Торговля — Vendure: канал на рынок (своя валюта, цены,
наличие, язык), сайт знает свой канал. Тексты — Payload: запись сайта по
домену (так уже узнаёт себя cbdin.ro, `CMS_SITE_HOST`).

## Устройство

1. **Реестр сайтов** — данные (`lib/source/<источник>/sites.json`):
   `id`, `hosts`, `langs` и основной язык, `market` (пакет рынка), `look`
   (опубликованный вид сайта), `channel` (канал Vendure). Хост без записи —
   сайт по умолчанию (`DEFAULT_SITE`; на машине — localhost).
2. **Адрес** — прокладка ставит сайт заголовком и переписывает `/<lang>/…` на
   `/<site>/<lang>/…`; страницы — `app/[site]/[lang]/…`, заранее собраны на
   каждую пару «сайт × его язык». Язык не своего сайта — 404.
3. **Языки** — переводы общие на все сайты (`lib/i18n/<lang>.ts`); сайт выбирает
   свои. Тип `Lang` — все языки витрины; язык сайта проверяется по реестру.
4. **Рынок** — пакеты рынков (`lib/markets/<код>.ts`): страна, валюта, индекс,
   регионы, телефон, предел THC, разрешённые категории, доставка и оплата.
   Сейчас `MARKET` — один на витрину; станет `marketOf(site)`. Клиентским
   частям рынок приходит пропсом от страницы.
5. **Вид** — у каждого сайта свой опубликованный вид; сборка выпускает стили
   всех видов блоками `[data-site="<id>"]`, корень страницы несёт `data-site`.
   Панель вида публикует вид своего сайта.
6. **Каталог** — источник по сайту: образец — набор данных сайта (полки
   Хорватии и Бельгии разные), Vendure — канал сайта.
7. **Тексты сайта** — имя магазина, обещания шапки, реквизиты, юридические
   страницы — запись сайта (образец — файл сайта, live — Payload).

## Порядок

- **Ш1.** Реестр сайтов и прокладка по хосту в шаблоне набора; страницы под
  `[site]`; один сайт — образец (поведение не меняется). Проверки: адреса,
  карта сайта, robots, `hreflang`, canonical — по хосту сайта.
- **Ш2.** Рынок, языки, контакты и реквизиты — по сайту.
- **Ш3.** Вид по сайту (стили блоками, панель — свой сайт).
- **Ш4.** Каталог по сайту (образец — данные сайта; Vendure — канал сайта).
  Рынок у Vendure — канал (Channel): товары заводятся один раз в общем
  каталоге, канал рынка берёт разрешённые на рынке, со своей валютой и ценами,
  языками описаний, налоговой зоной и НДС, доставкой и оплатой. Так уже
  продаёт cbdin.ro (канал `ro`, леи). Каналы `be` и `hr` заводятся кодом —
  заливкой каталога магазина (`vendure-seed`, `compose.catalogue.yaml`), не
  панелью (решение владельца 11.10.2026). Слово владельца 21.10.2026: «вендуре
  же подключай».
- **Ш5.** Магазин: одно приложение витрины из шаблона набора вместо копий;
  команда обновления из набора вместо ручного переноса. Слово владельца
  21.10.2026: «витрину не доделали, мы её далее будем править, и нужно будет и
  витрину, и скил обновлять, и пейлоад с вендурой — витрина к ним подключена».
  Значит: витрина правится в наборе один раз; магазин берёт её командой
  обновления; Payload и Vendure — данные всех сайтов, их правят заливки кодом
  в репозитории магазина, не панели.
- **Ш5а.** Payload: запись сайта на домен (коллекция сайтов, как у cbdin.ro —
  `CMS_SITE_HOST`): имя магазина, обещания шапки, реквизиты, юридические
  страницы, блог — по языкам сайта; витрина читает их по договору
  `/api/storefront/*` (`SOURCE=live`), чего админка не написала — из файлов
  сайта. Слово владельца 21.10.2026: «и пейлоад тоже подключай».
- **Ш6.** Бельгия: сайт `be` — языки nl, fr, en; пакет рынка BE; полки по закону
  (ниже); вид. Домен cbdbuy.be на общее приложение.
- **Ш7.** Хорватия: сайт `hr` на общем приложении (данные из `apps/storefront4`);
  домен cbdshop.hr — когда владелец даст.

## Бельгия — что можно продавать (сверить у юриста до запуска)

Поиск 21.10.2026, источники вторичные (официальные тексты FPS Health и FPS
Finance не найдены):

- косметика и кремы с CBD — продаются открыто;
- CBD внутрь (масла, капсулы, бомбоны) — «новая пища» ЕС (Novel Food), ни одного
  разрешения нет — как еду продавать нельзя;
- цветы для курения — легальны как «прочий курительный табак»: акциз,
  налоговый склад, уведомление FPS Health;
- предел THC — в источниках 0,2 % или 0,3 %: сверить.
