**Why:** checks compare each page to rules, not pages to each other or the buyer's path; the owner can't find everything and fears hidden systemic errors.

**How to apply:** after each batch of visual edits and before handover: (1) same kind of thing looks the same on every page, phone + laptop; (2) impeccable critique over the whole buyer path. Report by root cause. If the owner finds something the audit should have caught, extend the audit. Written into skill stages and CLAUDE.md (И523). See [[design-with-skills]].
