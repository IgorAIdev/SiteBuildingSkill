## Чем мерить

**Правило.** Семь проверок и съёмка. Пять — **храповики** (`check:css`, `check:craft`, `check:design`, `check:detect`,
`check:port`): база помнит сегодняшнее число нарушений, падение — только если стало больше. `check:open` и `check:urls`
— не храповики: неоткрывающаяся страница и несуществующий обещанный адрес — не долг на потом. Отрисованные — только на
сборке («Ловушки мерки»).

```
npm run check:css     # по файлам
npm run check:port    # переносимость: общий слой, токены, данные, валюта
npm run check:open    # каждая страница дерева открывается в next dev
npm run check:urls    # обещанное открывается, открытое обещано (по out/)
npm run check:design  # механическая половина impeccable: разметка и стили вместе
npm run check:craft   # по отрисованной странице (нужен поднятый сайт)
npm run check:detect  # детектор impeccable по отрисованной странице (нужен SITE=), храповик по страницам
npm run check:craft -- --page /bg/catalog/oils   # узкий прогон: одна страница, ~минута
                                                 # базу не трогает и вердикта не выносит
npm run sweep         # съёмка на 41 ширине: сетка 320…1600, швы и пиксель над ними, сложенные экраны
```

**Почему:** проверка, падающая с первого дня, живёт до первого «давай отключим».

## Список страниц задаёт дерево маршрутов, а не рука

**Правило.** Страницы — обход `app/**/page.tsx`: группы `(…)` отброшены, сегменты из данных (`[cat]` — полки, `[id]` —
товары, `[lang]` — языки). `tools/routes.mjs`: `all()` — каждый адрес (108, дешёвым проверкам), `sample()` — по одному
на форму и язык (дорогим). Образцы — двумя концами: полка полнее всех и пустее всех (13 карточек и 2 — ломается
вторая), товар с самой большой семьёй вариантов и без семьи. **Пустой список — сломанный разбор**: валит проверку.
* Личные страницы (корзина, оформление, кабинет) дерево обходит пустыми; `personal()` добавляет их полными,
  сессией из `kit.config.json` (`"sessions"`, хвост `#as=…`; И263).
* Запрос дерево не видит (к `page.tsx` не привязан), а находки и «ничего не нашлось» — другие раскладки: `"queries"` в
  `kit.config.json`, форма → строки (витрина-образец: `{ "/[lang]/search": ["q=cbd", "q=zzzz"] }`); форма не из дерева
  — предупреждение, кривая запись — выход (И345).
* Узкий прогон — `node tools/check-craft.mjs --pages <адреса>`: адреса дерева (`node tools/routes.mjs`), без `?token=`
  и `?edit=`, личная — `#as=<сессия>`; мерится сборка на своём порту (`SITE=…`), не сервер разработки (И765).

**Ловушки.** Список рукой не растёт — новая страница попадает под проверку после того, как дефект найдёт заказчик.
Карта сайта — не список: в ней нет `noindex`-страниц. Git Bash — с `MSYS_NO_PATHCONV=1`, иначе `/ro` становится
`C:/Program Files/Git/ro` и проверка отказывает «не подошли адреса дерева» (И771).

**Почему:** рукой стояло пять болгарских адресов из семи форм и двух языков — полка, «не найдено» и английская половина
не мерились ни разу.

### Семья `zIndex` и восьмой запрет

**Правило.** Открывающееся — в верхний слой (`<dialog>`, `popover`): открытое последним — сверху, Escape, возврат фокуса
и `::backdrop` даёт браузер; крестик нужен всё равно (пальцу Escape недоступен), сброс `<dialog>` — один на все окна.
Всегда висящее — имя `--layer-*`. Разрешены `var(--layer-…)`, ключевые слова (`auto`) и **однозначное** число: пока
слоёв в блоке меньше десяти, номер значит «выше соседа» (`z-index: 2` у подписи на снимке); двузначный целится выше
ЧУЖОГО (шапки, затемнения) — это и запрещено.

**Почему:** у соседей пилюля сортировки с `z-index: 71` лезла закрытой поверх шторки фильтров; запрет числа без имён
ссылался в пустоту — пять чисел прожили с ним одиннадцать дней.

## `check:open` — открывается ли страница в разработке

**Правило.** `check:craft` и свип ходят по `out/`, а часть проверок фреймворк делает только в `dev`. `check:open`
поднимает `next dev`, просит каждый адрес `all()`: код ответа и страница, а не экран ошибки; без браузера, полминуты.
Ставится **до** сборки: обе пишут в `.next`.

**Ловушки.** Сервер убивается группой процессов: `SIGTERM` родителю оставляет дочерний `next dev` жить, проверка «долго
идёт». Разогрев — по адресу на форму: четыре запроса к несобранной форме получают 500 («/bg/404 — 500», в одиночку 200).

**Почему:** у соседей `<Image>` с `fill` и `width` разом восемь дней ронял в разработке главную, каталог и поиск.

## `check:urls` — обещанное открывается, открытое обещано

**Правило.** **Каждый обещанный адрес открывается; каждый открытый обещан ровно один раз.** `<loc>` карты, `canonical`
и `hreflang` существуют файлом (адрес в никуда — поисковик перестаёт верить остальным); каждая страница стоит в карте
или сказала о себе `noindex`. По `out/`, секунда, сразу после `build:site`, и в `check:all`.

**Ловушки.** Экспорт кладёт рядом со страницей одноимённую ПАПКУ — «адрес есть» отвечало про папку (`index.html` там
нет), и на удалённую страницу проверка не покраснела. Намерение комментарием в карте до страницы не доходит (корзина и
оформление молчали о себе).

**Почему:** у соседей карта клеила `/en/` + болгарский путь: 84 адреса — «не найдено», 84 английских вне карты,
`hreflang` на несуществующего двойника.

## `check:design` — механическая половина impeccable

**Правило.** Запреты и рефлексы `impeccable` (порядок — `CLAUDE.md`, «Дизайн делается дизайнерскими скиллами»),
видимые по файлу, — семьи храповика, как `check:seo` для СЕО-скиллов (`docs/skills.md`). Разметка и стили вместе:
модуль — по ввозу, класс — по `className`, предок с `.pagehead h1` — по дереву; мерится основа и
`templates/storefront`. Зелёная — «новых приёмов нет», не «красиво». Реестр — `tools/design-families.mjs`, у семьи
строка источника. `DESIGN.md` (шаг 1 порядка, И300): `docValue` — число вида в описании (`#код`, `rgb()`/`oklch()`, px,

**Почему:** витрина проходила все проверки вёрстки и оставалась плохой (И271).

## `check:detect` — детектор impeccable по отрисованной странице

**Правило.** Карточка в карточке, прилипшая полоса, первый экран одной колонкой, прижатый заголовок, невидимое в покое
видны только на экране. Вендорена страничная сборка движка: один файл, правила — WebAssembly, без сети и запускателя
(`tools/vendor/impeccable/`: `VENDOR.json` — тег, коммит, хеши; `SOURCE.md` — лицензия). Дерево, 375 и 1440, обе темы,
прокрутка до низа; «невидимо в покое» и «ошибка скрипта» решает проход — замером и событием браузера. База по страницам (`tools/detect-baseline.json`) — узкий прогон выносит вердикт. Судьба правила одна
(`tools/detect-families.mjs`, тест — без остатка): семья — считается; выключено — вопрос уже у семьи набора; только
печать — вкус брифа и тексты заказчика. Сработало на решении набора (многоугольник главной кнопки прочитан «органикой») — прав набор, правило выключено с
причиной.

```
SITE=http://localhost:<порт сборки> npm run check:detect -- --pages /en,/en/catalog   # в ходе правки: тронутые, основной язык
SITE=http://localhost:<порт сборки> npm run check:detect                               # перед сдачей: всё дерево, все языки
SITE=… npm run check:detect -- --list firstScreen                             # находки семьи: страница, селектор, где видна
```

**Ловушки.** Хеши — до вставки; чужие адреса закрыты с первого запроса, после вставки — всё; чужой запрос — находка «детектор пытался выйти в сеть». Без `SITE=`, Playwright или при
чужом хеше — выход 2, «не проверено».

**Почему:** дизайн мерился только по файлу (И310).

### Проходы: тема, указатель, движение

* **Тема:** цвет через `light-dark()` — без тёмного прохода половина цвета не мерена. `colorScheme: 'dark'`, контраст,
  один язык; семья своя (тёмная и общая чинятся по-разному). **Цвет текста — оттуда же, откуда фон под ним**
  (палитра — к палитре, роль темы — к роли); медиазапрос меняет кегль и отступы, не ИСТОЧНИК. В файлах — `halfRole`
  (`check:css`). Подпись плитки «палитра + роль» в тёмной дала 1.12 при 4.5.
* **Указатель:** ширина решает раскладку, указатель — цель: `@media (pointer:
  coarse)`, ровно как `:hover` пишется в `@media (hover: hover)`, не `max-width` (планшет в альбоме — 1024 CSS-пикселя,
  а палец остался пальцем). Проход 768 и 1024 **с `hasTouch`** требует 44.
* **Движение:** «уменьшить движение» — что ещё движется. Сброс `styles/base.css` не гасит `element.animate()` и
  `scroll-behavior:smooth`; укачивает буквально — выключатель слушается. Переход 0.9с мимо сброса семья находит.

### Сорок четыре — не единственная норма

**Правило.** 44×44 — WCAG 2.5.5 (**AAA**); AA 2.5.8 — 24×24, **если то же действие есть у другого органа на экране**
(метки слайдера: 44 развели пять точек на четверть экрана, при шаге 28 ряд собран). Оговорка — `data-tap="24"` на месте;
ниже 24 никто.

**Ловушка.** Blink отдаёт 44 как 43.99997 (шаг раскладки 1/64 px) — допуск в этот шаг; 43.98 — находка (И776).

### Поле и заголовок

Из разбора чужих скиллов (`docs/skills.md`): `name` (подпись поля), `fieldZoom`, `autofill` — `controls.md`, «Телефон:
поле, окно и вырез»; находка поля — одна на страницу. `h1Lines` — заголовок не длиннее трёх строк (`H1_LINES`,
`tools/thresholds.mjs`); имя товара — данные, чинится роль. Ошибка скрипта — `check:detect` (`scriptError`).
Самопроверка — `selftest/craft-fields.test.mjs`.

### Обрезанный текст — та же беда, что вылезший за экран

**Правило.** Текст, срезанный своим блоком, свип не видит: `scrollWidth` > `clientWidth` у узла, чей блок режет (`hidden`/`clip`); полоса прокрутки не в счёт.
`nowrap` — «НИКОГДА не переносится» (подвал на 375 съел полслова); при `+` или `/` в названии — `<wbr>` («20% CBD+CBN»
срезан на букве).

### Нажатие обязано отвечать, и отвечать нашим

**Правило.** Рамка Android снимается `-webkit-tap-highlight-color: transparent` на `html` **парой** со своим откликом
(`noPress`: есть `:hover`, нет `:active`, `aria-` или `data-` состояния) — иначе нажимают дважды. `:hover` — в
`@media (hover: hover)`, иначе залипает (все 235 правил; последние четыре — в `packages/ui`).

### Шторка закрывается тем движением, каким пришла

**Правило.** Три выхода, все обязательны (И8): крестик (единственный видимый), Escape (клавиатуре; на телефоне его нет),
уход — прокрутка или свайп. Сторож ищет панель **по поведению**: `fixed`, половина экрана, целиком за краем.
`data-swipe` ставит обработчик жеста, не рука (рукой — обещание вместо факта). `<dialog>` приносит Escape, фокус и затемнение, но **не свайп** — на переезде его не терять.

### Мера строки: `ch` — это не знак

**Правило.** `66ch` при 15px — **81 знак** (`ch` — ширина «0»); мера выводится: колонка / настоящие знаки × 70 (здесь
58ch). Заголовок — долей колонки, текст — знаками на строку (66ch в 900px — 62 %, норма). Нижняя граница — с трёх строк
и когда место ЕСТЬ (390px, сорок знаков — норма).

### Контраст меряется пикселями

**Правило.** `getComputedStyle` по предкам — отсев (псевдоэлемент, сосед, фото не видны); провал подтверждается
пикселями: буквы `color: transparent` (фон и вуаль остаются), снимок, среднее под строкой.
Вуаль — по яркости под словами без вуали, на нескольких ширинах (`object-fit: cover`), худшая. **Цель — на полторы ступени выше порога** (при 4.5 ровно — одна из 17 вышла 2.8).

**Ловушка.** Вуаль по снимку в canvas «по геометрии» разошлась с правдой втрое. Из 91 «нарушения» настоящих 15.

### Что считать невидимым — зависит от того, кто смотрит

Глазу — за краем по горизонтали (чекмедже на −320) не мерится. Скринридеру — заголовок под `clip-path` в лестнице
есть; нет — `display:none`, `visibility:hidden`, `aria-hidden`, `inert`. Дно текста — что за ним: `position: fixed`
не в счёт (помощник давал цене 4.44:1).

### Переделка старой анимации — только после замера

**Правило.** «Только `transform` и `opacity`» — новому коду (`width`, `height`, `top`, `padding` — раскладка каждый
кадр). Старое переделывают, **показав потерянные кадры** (шапка на телефоне: худший 17мс при пороге 24; `tools/jank.mjs`
в наборе нет). Исключение — комментарием: точка 6px → 17px через `scaleX` — эллиптические торцы.

## `sweep` — 41 ширина

**Правило.** Ломается между ширинами. `sweepWidths()` (`tools/seams.mjs`): шаг 40 от 320 (WCAG 1.4.10) до 1600, шов и
пиксель над ним (820 / 821), сложенные 690, 829, 836, 842 (И227); пороги — `LAYOUT` (`tools/thresholds.mjs`).
Переполнение, столбики, сироты, ступеньки заголовков (валит), кадр меньше половины снимка, скачки высоты (смотреть);
«текст и кадр» — только здесь.

## Ловушки мерки

**Правило.** Находка не сходится с глазом или число не меняется, где обязано, — сперва мерка и подача. Нестабильная
проверка — дефект проверки.

* **Только на сборке:** `check:craft`, `check:detect`, `check:seo`, `sweep` — по `npm run build:site` на **простом**
  статическом сервере; на сервере разработки обход портит манифест — все страницы 500. Исключение — `check:part` в
  одну полосу (И765). Не `next build` (оставляет панель настроек — контраст находит
  несуществующее), не `serve -s` (всё на `index.html` — находка с чужим адресом).
* **Убедиться, что открыт САЙТ** (`header` и `main`), иначе падать: `python3 -m http.server` (`/product` ≠
  `product.html`) молча не мерил три страницы из пяти.
* **Ждать сигнала, а не времени:** 200, `header` и `main`, витрина сошлась с набором, прокрутка доехала
  (И765), а не пауза; короткие 500 после правки `tools/` — перестановка: дождаться 200. Дольше предела — «не проверено»
  с именем страницы (И777). Ручной замер на сервере разработки — так же: то, что рисует браузер после загрузки
  (кнопки листания `RailPager`), появляется через секунды; заказчик снял главную раньше и решил, что стрелки удалены,
  мой первый замер насчитал 0 кнопок. Ждать признак в разметке и сказать заказчику, что такие части опаздывают.
* **Ломать исходник, а не `.storefront/`:** `check:part` переставляет витрину из источников (`lessons.md`).
* **Гуляющая находка — дефект проверки:** второй снимок, снятая прокрутка (`controls.md`).
* **Имя ключа:** ширина — `viewport`; `viewportSize` в контексте молча игнорируется — ширины одинаковы, снимки одного
  размера до байта. Мерку проверяют на числе, которое ОБЯЗАНО измениться.
* **Цвет — не всегда `rgb()`:** `oklch(from var(--accent) …)` приходит `oklch(0.8 0.11 219)`, `color-mix()` — как
  есть; разбор «три числа — RGB» мерил выдуманный цвет. Цвет — пикселем на `<canvas>` и обратно.
* **Снятый слой уносит текст:** прятать (`visibility:hidden` у `fixed`, `sticky`) только чужое (`!e.contains(el)`) —
  иначе с колонкой прячется и кнопка («Apply filters» 1.31 : 1).

## Свойства сторожа

**Правило.** Каждое куплено зелёным сторожем при живом дефекте.
* **а. Меряет видимое покупателю,** а не то, из чего собрано (значки мерили таблицей размеров, а плющила раскладка).
* **б. Читает число из источника** (швы 1010 и 920 рукой покраснели на верной раскладке).
* **в. Падает, когда правило снимают** — обратный ход; иначе сторож — комментарий.
* **г. Доходит до проверяемого** (`python3 -m http.server`; разогрев `next dev`).
* **д. Краснеет в обе стороны:** обещан несуществующий адрес — и не обещана страница; шов вне трёх — и разрешённый шов
  без стилей; правило снято — и сторож молчит.
* **е. Не требует того, чего не позволяют слова:** кричащая на верное учит себя не читать. «Столбик обрывков»
  (`check:craft`, свип) мерит **заполнение**: строка от 60 % колонки — перенос сделал всё; дефект (коробка 560, текст
  в 90) даёт 0.33.

**Правка без сторожа — со сроком годности:** показанное заказчиком глазом закрепляется проверкой **в тот же заход**
(`<select>` вместо поля унёс плашки городов — держались памятью).

## Новая семья: результат, поломка, первый прогон

**Правило.**
* **Меряется результат, не текст правила:** `railTail` — видимый низ ряда против низа ряда; `tileGrow` — рост кнопки
  плитки под пальцем (И764), а не строка `--ctrl-h`.
* **Испытывается поломкой:** `page.addStyleTag` возвращает дефект (перенос строки статьи, рисунок плитки 48) — семья
  находит (17 px пустоты; «Add» ×24 ростом 48), на исправленной молчит.
* **Первый прогон — по всему, что задевает:** `railTail` кричала на сетку ноутбука, `tileGrow` — на кнопки героя;
  сужено по смыслу: ряд тянет карточка за краем окна, плитка — ячейка со снимком или заголовком.
* **Починка не будит соседа:** многоточие разбудило `clip` и `offColumn`, верно — место под две строки у
  заголовка; после правки — узкий прогон всеми семьями.

**Почему:** тест читал `min-block-size: 2lh` из файла, а пустота под статьями вернулась (И762).

## Исключение объявляется там, где принято

**Правило.** Верный случай, который проверка читает как дефект, объявляется **на месте** — атрибутом или переменной у
блока, а не списком в проверке (переехавший блок тихо выпал бы из-под неё). Исключение — решение вёрстки.

| где | чем объявлено | что значит |
|---|---|---|
| сетка | `--cols-min:1` | столбик здесь верен: в ячейке длинный текст |
| орган | `data-lines` | подпись многострочна: ширину даёт ряд, а не слово |
| орган | `data-tap="24"` | цель 24: то же действие есть у другого органа на экране |

## Проверка, которая стоит рабочего дня

**Правило.** Прогонов за правку три-четыре: двадцатиминутная проверка — два часа стоящей работы (счёт заказчика).
1. **Проверка ЖДЁТ, а не считает:** 1190 с на 220 открытий — сеть и шрифты; полосы дали 334 с при тех же находках.
   Число полос — **ручка, а не догма** (`CRAFT_LANES`): на слабой машине убавить; при четырёх прогон упирается в
   отрисовку.
2. **Порядок находок параллельного прогона не свой:** семьи **сортируются перед печатью**; об упавшем сервере кричит
   одна полоса.
3. **Нельзя ради скорости** мерить шесть ширин сжатием окна: `srcset` выбран **на загрузке** — ложные находки и пропавшие
   настоящие. Нельзя сокращать список страниц. Быстрая ложь дороже медленной правды.
4. **Гонять ту, что красная;** цепочку — перед первым пушем и сдачей.

**Чем мерится:** `check:all` печатает секунды; дольше пяти минут — сколько страниц и полос.

## Чем каждая проверка оборачивается в деньгах

**Правило** заказчика, старше вкуса: решение — по поиску, ИИ-ответам, числу покупателей и продажам. Обманом — ничего
(набитые слова, скрытый текст бьют по всем целям).

| проверка | чем оборачивается |
|---|---|
| текст в разметке, а не после гидратации | поиск и ИИ видят магазин, а не пустую оболочку |
| прыжок вёрстки (`width`/`height` у картинок, семья `jump`) | CLS — множитель в ранжировании и отказах |
| вес снимка вдвое больше места (семья `weight`) | LCP: покупатель уходит до первой строки |
| цель нажатия 44×44 (семья `target`) | половина покупок делается пальцем |
| контраст (семья `contrast`) | страницу дочитывают, а не закрывают |
| лестница заголовков (семья `heads`) | по ней машина понимает, о чём страница |
