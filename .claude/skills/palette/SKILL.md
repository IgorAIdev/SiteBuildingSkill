# Палитра магазина

Цвет витрины: какие краски нужны и на что, как из трёх красок владельца
строится остальное, чем работает каждая ступень и чем это меряется.
Исполнение — `tools/palette.mjs` (строитель и замер одним кодом),
`tools/check-palette.mjs` (замер), `tools/palette-css.mjs` (выпуск), стенд и
лист. Пять работ палитры: показать, куда нажать · сказать смыслы цветом ·
читаться по закону и глазом · быть двумя честными темами · строиться из трёх
красок замером (откуда каждая — `references/build.md`). Порядок дизайна
(контекст → … → polish) — `CLAUDE.md`, «Дизайн делается дизайнерскими
скиллами»; краски — потом, здесь.

| Чей вопрос | Скилл |
|---|---|
| краски, семь семей, шкала, роли по элементам, строитель, замер WCAG и APCA | `palette` |
| роль на полу, лист на палубе, затемнение, отрисованная тёмная тема, знаки | `craft`, `color.md` |
| размер, расстояние, ритм | `scale` |
| товар и цена как данные | `shop` |

## Порядок работы: новая палитра за десять шагов

Закон читается целиком при любой правке красок, ролей и строителя; новая
палитра идёт шагами по порядку.

| Шаг | Что делается | Закон · разбор |
|---|---|---|
| 1 | спросить у заказчика ТРИ краски на тему — фон, текст, фирменный; серые, статусы и состояния не спрашивать, они считаются; словами «бумага» и «чернила» с ним не говорить | таблица фактов ниже · `build.md` |
| 2 | проверить марку: коридор светлоты, ΔE ≥ 25 от красного и от каждого сигнала | пп. 7, 14, 19 · `build.md` |
| 3 | проверить бумагу: почти-белая, тон от ниши, хрома ≤ 0.02 | п. 19 |
| 4 | проверить чернила: не чёрные и не белые; на заливке — замером | п. 19 |
| 5 | выпустить: `npm run palette`; строитель считает всё остальное, в выпущенное руками не лезут | пп. 1–15 · `palette.md` |
| 6 | замерить: `npm run check:palette`; находка чинится краской (шаги 1–4) или правилом строителя, никогда порогом: порог, снятый ради одного набора, снят для всех | пп. 1–18 |
| 7 | раздать роли: `styles/tokens.css` читает ступени по `roles.md` строка в строку | пп. 16–25 · `roles.md` |
| 8 | пройти тёмную тему отдельно: `npm run check:theme` | п. 26 |
| 9 | показать глазами: стенд и лист, обе темы; слово заказчика — в `docs/gate.md` | п. 27 |
| 10 | записать и увезти: `node install.mjs --palette "Имя" ../мой-сайт` | И213 |

Шаг 9. Числа отвечают «пройдёт ли проверку», заказчик — «как магазин будет
выглядеть» (CLAUDE.md, «Выбор — глазами, а не списком»). Стенд
`npm run palette:stand` — выбор: наборы рядом на одной карточке. Лист
`npm run palette:sheet` — состав: все краски с подписью работы (И214).
`npm run palette:builder` — ход построения. Всё, что открывается, снято
открытым. Набор называется словом заказчика — с датой в `docs/gate.md` (И198).

Шаг 10. Едут ключом, а не памятью (И213): `styles/palette.json` (образцы —
`templates/palette.json`), `styles/palette.css`, `tools/palette*.mjs` с
`palette-profile.json` и `palette-builder.html`, этот скилл целиком.

| Семья | Для чего | Ступени |
|---|---|---|
| нейтраль `n` | ничего: лист, карточка, органы, текст, линии | 12 ступеней |
| марка `a` | «сюда нажать» — одно действие | 12 ступеней + нажатие |
| ошибка `e` | деньги теряются сейчас: нет в наличии, поле не принято | 2 · 9 · 11 + знак |
| скидка `sale` | дешевле, чем было — плашка и прежняя цена | то же |
| внимание `warn` | будет стоить потом: осталось двое, срок | то же |
| успех `ok` | проверено: в наличии, добавлено, заказ принят | то же |
| сведение `info` | просто факт: доставка 3–5 дней, производитель (профиль CBD: ТГК) | то же |

Рукой называются **три краски на тему** — бумага, чернила, марка; остальные
считаются. Второй марки нет: у минимализма одно действие на экран, и две
марки рядом путают, какое главное. Восьмой семьи нет, пока у магазина нет
восьмой работы (почему именно эти — `references/roles.md`, «Семь семей
смысла»). Набор живёт в приложении, `styles/palette.json`. Красный «нет в
наличии», оранжевый «мало осталось» и зелёный «в наличии» — постоянные
строителя; скидка — рубиновая красной семьи (И554; прежнее — И211), сведение —
синее эталона (И215). Набор вправе назвать любую из них своей — и обязан,
когда марка ближе ΔE 25 к общей (И216; `palette.md`). Сверх красок тема
может назвать силу тени под подписью на снимке, `caption` 1–100, по умолчанию
40 (И451); пол палубы набор не называет — он всегда заливка марки (п. 21).
Пять сигналов, а не четыре: сообщение о ФАКТЕ («доставка 3–5 дней») нельзя
красить ни успехом, ни вниманием — оба врут.

## Закон: палитра — шкала из двенадцати ступеней

На каждый смысловой цвет — нейтральный, фирменный и пять сигналов — строится
шкала, и работа ступени назначена один раз для всех: 1 лист, 2 карточка, 3–5
контрол (покой, курсор, нажатие), 6 разделитель, 7–8 граница, 9–10 заливка
кнопки, 11–12 текст. Структура — Radix Colors, пороги — WCAG 2.2. Номера
пунктов стабильны: на них ссылаются справочники и архив `docs/rules.md`. После
каждого — *Меряет* (замер или семья), *Разбор* (`references/…`), И-номер.
Правило без дефекта, названного в разделе скилла (`palette.md`), — чужое мнение;
журнал `docs/rules.md` заморожен — архив номеров.

1. **Состояние — соседняя ступень, а не процент от краски:** процент у
   тёмной кнопки ответа не даёт. Шаг заливки — 4.2 ΔL\* в светлой, 5.5 в тёмной
   (`SOLID_GAP`). *Меряет:* `check:palette`, «наведение кнопки заметно / не
   обвал». *Разбор:* `palette.md`, «Четыре дефекта», §1.
2. **Ступень наведения отмеряется ОТ ЗАЛИВКИ,** а не гонится к отметке
   эталона: иначе яркая краска обваливается, а тёмная не двигается вовсе.
   *Разбор:* `palette.md`, §2.
3. **В светлой теме состояние темнит, в тёмной светлит** — уводит прочь от
   бумаги. *Разбор:* `palette.md`, «Направление».
4. **У нажатия своя ступень, вдвое дальше наведения.** В шкале её нет, и это
   дыра: на телефоне курсора нет, нажатие — единственный ответ. **Шаг руки
   один у всех органов** (И702): залитая кнопка, тихая, строка и половинка
   счётчика меняют светлоту под рукой на одну величину — доля слоя состояния
   одна (`--state-hover` 8 %, `--state-press` 12 %, `STATE.step`), вуали
   строителя подбирает под шаг тихой `handStep`. *Меряет:* `hand-step`
   (`groundChecks`, днём: меньший шаг ≥ 0.6 большего); ночью разброс открыт
   (`docs/open.md`). *Разбор:* `palette.md`, «Ступень, которой в шкале нет»,
   «Шаг руки один».
5. **Граница органа управления и кольцо фокуса — замером, а не номером:**
   берётся первая ступень, которая порог 3 берёт. *Меряет:* `check:palette`, «граница органа управления
   на каждом полу», «кольцо фокуса на всех поверхностях». *Разбор:*
   `palette.md`, §3.
6. **Знак на заливке выбирается, а не хранится** — из белого и чёрного, и
   держит ОБЕ меры: WCAG 4.5 и APCA Lc 60 (`bothHold`, И559). Не держит ни
   белая, ни чёрная — заливка сигнала сдвигается тем же тоном (`solidFor`),
   марка — до построения (шаги 2–4, `fitPalette`). *Меряет:* `check:palette`,
   «знак на кнопке покупки читается глазом (APCA)». *Разбор:* `palette.md`,
   «Знак на заливке не хранится».
7. **Фирменный отличается от красного не меньше чем на ΔE 25.** Кнопка
   покупки — то, что хотят нажать, красный — то, что хотят заметить как беду.
   Тоном не мерится: золото в 43° от красного, вино в 3°. *Меряет:*
   `check:palette`, «фирменный и красный — разные краски». *Разбор:*
   `palette.md`, §4.
8. **Лестница строится в обе стороны и не схлопывается** (И189): от бумаги
   через краску к чернилам, в тёмной тем же правилом с другим направлением;
   наименьший шаг соседей не меньше 0.6 L\* — самой тесной пары эталона.
   *Меряет:* `check:palette`, «лестница не схлопывается». *Разбор:*
   `palette.md`, §5.
9. **Красный — такая же шкала, как марка** (И190): на нём «нет в наличии» и
   текст ошибки, и он проходит те же правила — лестница, текст на карточке,
   знак на заливке. *Разбор:* `palette.md`, §6.
10. **Метрик две, и обещание дано в одной** (И191). WCAG — ворота (в основе
    EN 301 549), но эталон обещает только APCA: 11-я ступень даёт Lc 60 на
    2-й, 12-я — Lc 90. Одиннадцатая берётся ЗАМЕРОМ, как граница и кольцо, а
    не номером. *Меряет:* `check:palette`, «приглушённый текст держит
    обещание эталона». *Разбор:* `palette.md`, §7.
11. **Правило, которого эталон сам не держит, правилом не становится:** новый
    порог сначала гоняется по шкалам эталона. *Разбор:* `palette.md`, «Два правила исследования».
12. **Середина лестницы держит тон марки** (И195). Ступени 1–8 не кладутся
    прямой от бумаги к краске (она идёт через серое): тон — у краски,
    светлота — из профиля, насыщенность — доля по дуге ближайшей по тону
    породы (`tools/palette-profile.json`); вне охвата экрана гасится
    насыщенность, а не светлота. *Разбор:* `palette.md`, §8.
13. **Концы лестницы — краски заказчика как есть** (И195): первая ступень ЕСТЬ
    бумага, девятая цветного ряда ЕСТЬ марка, двенадцатая ЕСТЬ чернила.
    *Разбор:* `palette.md`, §9.
14. **Красок сигналов пять, и все различимы попарно** (И196): марка, красный
    «нет в наличии», оранжевый «осталось двое», зелёный «в наличии», плашка
    скидки; порог ΔE 25. Скидка цвета марки пропадает рядом с кнопкой
    покупки, скидка красного читается предупреждением. Статусной краске три
    ступени, не двенадцать: тихий фон, заливка, текст. *Меряет:* `check:palette`,
    «… и … — разные краски». *Разбор:* `palette.md`, §10.
15. **Палитру мало проверить — её надо уметь выпустить** (И194). Краски — в
    `styles/palette.json`, математика — в `tools/palette.mjs`, выпущенное — в
    `styles/palette.css`; шкалы сайта читают палитру переменной (`--a-9`,
    `--on-a-9`, `--a-press`), а не повторяют числами. Новый `#RRGGBB` в стилях
    — место, где правда разойдётся молча. *Меряет:* `palette-css.mjs --check`
    внутри `check:palette` (отставший выпуск — находка).
16. **Цвет на экране даёт раздача ролей, а не выдумка** (И462, И472). Пол и
    текст — нейтраль; вторые органы — по таблице ролей (`roles.md`: покой n3,
    выбранное — тональное a5 или сплошное a9); сигналы — где есть смысл;
    чужие марки (кошельки, мессенджеры) — краской своей марки (`--mark-*`);
    сплошная марка — одно главное действие. Серый сайт — роли не розданы, а не
    нехватка краски. Тон марки на тихих кнопках («Brand tint») не
    предлагается. *Разбор:* `palette.md`, «Роли
    раздаются».
17. **Красный — краска беды, и места у него названы** (И463). Красный и его
    семья (бордо, вино, терракота, коралл — сектор `RED` в
    `tools/thresholds.mjs`) читаются тревогой (Apple HIG, Material 3).
    *Меряет:* `check:palette` (ΔE до красного), `redFamily`. *Разбор:*
    `palette.md`, «Красный — краска беды».

    | где | красный `e` | марка красной семьи |
    | --- | --- | --- |
    | «нет в наличии», поле не заполнено или не принято, платёж отклонён | да — `e9` / `e11` / `e2` | нет |
    | скидка — плашка «−20 %», прежняя цена | да — своей краской `sale`, красной можно, если до ошибки ΔE ≥ 25 (п. 14) | нет |
    | знак «убрать» под курсором, «удалить адрес» | да — `e11`, знак, не строка | нет |
    | главное действие экрана (одно) | нет | да, если до красного ΔE ≥ 25 (п. 7) и ошибка названа своей краской |
    | тихие кнопки, плитки, выделение, фон раздела | нет | нет — тихая марка такой палитры нейтральна, строитель гасит её сам |
    | цена, заголовок, ссылка, украшение | нет | нет |

    Марка красной семьи законна, но её место — одна кнопка: розовый тон на
    трети экрана читается тревогой там, где тревоги нет. Строитель узнаёт
    такую марку (`redFamily`) и выпускает её `--quiet-tint-*` вуалью чернил.
    Цвет такому сайту даёт выбор другой марки, а не второй тон красного.
18. **Роль мерится на своём полу, а сайт — целиком** (И554). На сайте —
    нейтраль, одна марка и красный там, где внимание; третьего тона нет,
    скидка — красной семьи. Ночью каждый элемент стоит на том же месте
    лестницы, что днём: полоса шапки и подвал — одна краска, темнее карточек,
    на ступень над страницей (днём — самое тёмное, ночью — не светлее листа).
    Роль органа и тихий текст держат порог на **каждом** полу 1–5 обеих тем,
    а не на одной ступени (И556). Порядок без расстояния — не порядок (И568):
    ночью всё, что лежит на странице, поднято на уровень листа (ступень 4,
    1.30 над страницей), полоса отстоит от страницы не меньше 1.25 : 1 в
    обеих темах. *Меряет:* `deck-order`, `deck-apart`, `sale-kin`,
    `border-floors`, `soft-floors` (`groundChecks`: их читают `check:palette`
    и «Guaranteed» панели вида); на отрисованной странице — семья `edge` в
    `check:craft` (граница поля, выбора, галочки и счётчика днём и ночью).
    *Разбор:* `palette.md`, «Сайт целиком, а не роль».

Раздача и целое, дальше пп. 19–27 (разбор — `palette.md` и `build.md`):

19. **Краски проверяются до построения** (шаги 2–4). *Марка:* L\* 45–62 — под
    белый знак, 83–91 — под тёмный; 63–82 — мёртвая зона, где ни белые, ни
    чёрные чернила не дают Lc 60; ниже 45 — лестница тесная, строитель покажет
    цену числом шага; от красного и от каждого сигнала — ΔE ≥ 25 (пп. 7 и 14);
    марка одна на обе темы, если её L\* в 45–62, иначе тёмная поднимается в
    коридор, и это записано у набора словами. *Бумага:* почти-белая, не
    `#FFFFFF` (чистый белый на большой площади бликует); тон от ниши и марки
    (тёплый для натуральной полки, холодный для клиники), хрома ≤ 0.02;
    тёмная — L\* 5–8, не чёрная. *Чернила:* не чёрные и не белые (Material:
    тон 10 / 90; в тёмной текст не выше L\* 96); тёплые — к тёплой бумаге; на
    насыщенной заливке — не они, а белое или чёрное замером. *Разбор:*
    `build.md`, «Шаги 1–4».
20. **Марка ночью не насыщеннее дневной** (правило 5 тёмной темы, порог
    различения 0.02 OKLCH; И766): ночная краска набора поднимается по
    светлоте, насыщенность держит дневную. *Меряет:*
    `selftest/theme.test.mjs` (готовые наборы), `check:theme` (сайт).
    *Разбор:* `palette.md`, «Марка ночью».
21. **Основной цвет один, и марка — сверху донизу** (И694, И697, И706). В
    любом наборе и в обеих темах палуба — заливка марки a9 (`deckFor`):
    шапка шторки, подвал, верхняя полоса, тёмный раздел, кнопка связи;
    выбранный вариант и текущая страница — той же краской (`--chosen`); роли
    главной кнопки объявлены на каждом полу. Сцена героя берёт пол палубы,
    только когда марка тёмная (`DARK_KIN`). Исключение «по палитре» — дефект.
    Сплошных тёмных точек на светлом поле нет. *Меряет:* `one-main`, `chosen`,
    `chosen-one-main`, `hero-one-dark`; перед показом — счёт по зонам: шапка,
    первый экран, тело, подвал. *Разбор:* `palette.md`, «Основной цвет один».
22. **Пол страницы днём n2, ночью n1** (И699). Лист над светлым полом держит кромка и тень, не шаг светлоты
    (И592). *Разбор:* `palette.md`, «Основной цвет один»; `roles.md`,
    «Поверхности».
23. **Цвет в стилях не рождается** (И295; CLAUDE.md, «Делается только
    правильно»): литерал или `color-mix` с долей числом или ручкой узла —
    находка семьи `colorOut` в `check:css`. Доля ролью состояния
    (`--state-hover`, И229) законна; нужной краски нет — новая роль в
    строителе, с замером, а не смесь на месте.
24. **Переход состояния — ход между двумя ролями** (И487): `--pop` →
    `--pop-hover`, `--quiet` → `--quiet-on`; между ними `color-mix(in oklab,
    var(--покой), var(--рука) calc(var(--ход) * 100%))`, где `--ход` в стилях
    принимает только `0` и `1`. Ход с `.5` или ручкой — находка: середина
    перехода застыла бы краской, которой нет в палитре. Роли «середина» нет
    намеренно. *Разбор:* `palette.md`, «Цвет в стилях не рождается».
25. **Вид, которого нет в опубликованном, роли не получает:** невыбранный
    заказчиком вариант снимается вместе со своим видом, а не получает пару
    «светлая плашка вне темы» в строителе (`palette.md`, п. 25). Замеры ролей по полу —
    `groundRoles` / `groundChecks` в `tools/palette.mjs`.
26. **Тёмная тема — отдельно:** роли те же, значения другие внутри
    `light-dark()`; проверяется не подстановкой, а глазами и замером —
    `npm run check:theme` (шесть правил: `craft`, `color.md`). Контраст
    меряется против самой светлой тёмной поверхности, а не против фона;
    затемнение под окном тёмное в обеих темах и не собирается из чернил.
27. **Инструмент, которым палитру строит САМ заказчик (панель вида), верен по
    построению** (И275): принимает намерение — цвет марки, бумагу тёплую,
    нейтральную или холодную, чернила — и выдаёт только набор, прошедший весь
    замер в обеих темах (`fitPalette`); что подвинуто — одной строкой, списка
    ошибок заказчик не видит. Замер (`auditPalette`) — инструмент того, кто
    ведёт набор.

## Чем мерить

`check:palette` не советует: называет число и норму. Тесты и стенды:

| Проверка | Что сторожит |
|---|---|
| `npm run check:palette` | лестница, текст на карточке, знак на заливке, граница и кольцо, пять сигналов попарно, обещание APCA; отставший выпуск |
| `npm run palette` | выпуск `styles/palette.css` из `styles/palette.json` тем же кодом, что мерит |
| `npm run check:theme` | цвет обеих тем на отрисованной странице (скилл `craft`) |
| `npm run test` | строитель: обратный ход каждого правила, APCA против чисел эталона, Oklab туда и обратно, лист показывает всё выпущенное |
| `npm run palette:stand` · `palette:sheet` · `palette:builder` | выбор, состав и ход построения — глазами заказчика |

Замки (факты из кода И219, число словом сверяется с кодом, формула привязана
к строке кода И218, хук правки пересобирает таблицы И260, выпущенное
сверяется байт в байт) и как растёт скилл — `.claude/skills/README.md` и
`check:rules`.
