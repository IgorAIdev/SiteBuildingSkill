cbdshop.bg is the first storefront of the owner's monorepo `CBD_ecommerce_eu` (docs/skills.md, audit 19.09.2026); the cbdin engine runs at `vendure.cbdshop.bg` (docs/open.md). 04.10.2026 the owner: «блог хорошо сделан в cbdshop.bg… текста сами тоже можно скопировать, только переделать… измени, чтоб они не были точной копией».

**Why:** I first treated cbdshop.bg as a third party and refused to reuse its texts; checking the kit's own records showed it is his.

**How to apply:** before refusing to reuse a site's content, check docs/skills.md, docs/decisions.md and memory for whether it is the owner's. His texts → base for rewrites (own order, headings, examples, market law), not translations. The Vendure server code for cbdin likely lives in `CBD_ecommerce_eu` — ask before working in that repo ([[skill-scope-not-shop]]). Related: [[gymshark-reference]], [[allbirds-reference]].
