# 71 · Текстовая кнопка с подчёркиванием

Источник: HyperUI, «Marketing → Buttons → Quiet text and underline buttons»
(https://www.hyperui.dev/components/marketing/buttons), лицензия MIT.
Взято устройство: слово с подчёркиванием (`underline`, толщина 2, отступ 4,
под рукой подчёркивание темнеет) и слово без подчёркивания с тоном под рукой.
Вид — свой: краски палитры набора, кольцо набора.
