# 72 · Кнопка с боковой кнопкой-знаком

Источник: HyperUI, «Application → Button Groups → Main and Secondary»
(https://www.hyperui.dev/components/application/button-groups), лицензия MIT.
Взято устройство: текстовая кнопка и малая кнопка со знаком в одной группе встык,
углы только по внешним краям. Вид — свой: заливка марки и контур набора.
