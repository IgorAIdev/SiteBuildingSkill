## Выдача по главному запросу

Регион, язык, устройство, дата. Типы страниц топ-10 (сколько полок,
товаров, статей, аптек, маркетплейсов). Title пяти первых — дословно.
Есть ли ответ нейросети. Вывод: какой тип страницы выигрывает.

## Факты страницы

Каждый — с источником (данные магазина, протокол, регулятор с датой).
Меняется с ассортиментом — токеном: `{count}`, `{priceFrom}`,
`{strengths}`, `{mgRange}`, `{volumes}`, `{spectra}`, `{pricePerMgFrom}`,
`{deliveryDays}`, `{freeShipFrom}`. Нет факта — фразы нет.

## Сниппет

2–3 варианта title и description по формуле типа; выбранный и почему.

## План текста

Над сеткой (≤ 40 слов) · разделы под сеткой: подзаголовок-вопрос → какую
задачу покупателя закрывает · таблица, если есть данные.
