# Досье рынка: какие запросы набирают покупатели

Содержание: вход и происхождение данных · подсказки Google (бесплатно) ·
выдача · частоты DataForSEO · импорт готовой выгрузки · слово рынка и
ловушки · что известно о рынках RO, HU, BG · свежесть.

Новый рынок с нуля — порядок в [research.md](research.md); здесь —
инструменты сбора.

Без досье текст пишется словами автора, а покупатель ищет своими. Досье —
это список фраз, которые реально набирают, с происхождением каждой, и
состав выдачи по головным фразам: он говорит, какой тип страницы
выигрывает.

## Вход и происхождение данных

Страна и язык — отдельно: `RO/ro`, `RO/hu`, `RO/en` — три разных набора
запросов одной страны. Исследование и первый текст — на главном языке
рынка; остальные языки получают свой сбор, а не перевод.

| метка | что значит | что доказывает |
| --- | --- | --- |
| `AC` | подсказка Google, снятая `suggest.mjs` с датой | фразу набирают; выше в списке — чаще; объёма нет |
| `SERP` | выдача по фразе (Google через DataForSEO или заместитель) | какой тип страницы выигрывает; title соседей |
| `VOL` | частота Google Ads (DataForSEO, Keyword Planner) | порядок спроса; близкие формы могут быть слиты |
| `GSC` | Search Console своего сайта | настоящие показы и клики своих страниц |
| `H` | гипотеза редактора | ничего; в брифе так и помечается |

`0` и `null` — разные вещи: ноль — замерили и не нашли, `null` — не
мерили. Ноль у CBD может значить запрет рекламы, а не отсутствие спроса
(Google Ads не отдаёт объёмов по CBD в части стран). Рекламная
«competition» — не органическая сложность, KD её не называть.

## Подсказки Google — бесплатно, первым делом

```sh
node <seo-content>/scripts/suggest.mjs --hl ro --gl ro \
  --seeds seeds-ro.txt --expand "ulei cbd,capsule cbd" --out ac-ro.json
```

Скрипт ходит на открытую точку подсказок Google по одной фразе в секунду,
пишет сырьё с датой и сводку: фраза, затравка, место в списке. Блокировка —
пауза и продолжение, не обход.

Затравки — десять групп; пример на ro:

| группа | примеры |
| --- | --- |
| ядро | `cbd`, `ulei cbd`, `cbd ulei` |
| народные слова | `ulei de canabis`, `ulei canabis`, `picaturi cbd` |
| форма | `capsule cbd`, `crema cbd`, `unguent cbd`, `jeleuri cbd`, `vape cbd`, `pasta cbd` |
| сила и мера | `ulei cbd 10%`, `ulei cbd 1000 mg`, `capsule cbd 25 mg` |
| состав | `ulei cbd full spectrum`, `ulei cbd izolat`, `cbd fara thc` |
| коммерция | `ulei cbd pret`, `cumpara cbd`, `magazin cbd`, `ulei cbd farmacie`, `ulei cbd emag` |
| доверие | `ulei cbd pareri`, `ulei cbd recenzii`, `ulei cbd original` |
| вопросы | фраза + `ce este`, `cum se foloseste`, `legal`, `efecte secundare` — вопросное слово **после** фразы |
| для кого | `ulei cbd caini`, `cbd pisici` |
| место | `cbd romania`, `cbd bucuresti` |

Расширение алфавитом (`фраза a` … `фраза z`) — для 3–5 головных фраз.
Короткие латинские затравки (`gel cbd`, `crema cbd`) возвращают испанские и
итальянские фразы: сводка отбрасывает фразы не того языка по словарю
затравок, остальное читает редактор.

## Выдача

По 10–20 головным фразам записать для каждой: типы страниц топ-10 (полка,
товар, статья, главная, маркетплейс, аптека), title пяти первых, есть ли
ответ нейросети. Правило маршрута — в [intent-map.md](intent-map.md).
Заместитель без ключа — DuckDuckGo (индекс Bing): для Bing и ChatGPT это
прямой замер, для Google — сигнал; помечать `SERP-proxy`.

## Частоты DataForSEO — когда есть ключ

```sh
DATAFORSEO_LOGIN=… DATAFORSEO_PASSWORD=… node <seo-content>/scripts/volumes.mjs \
  --location 2642 --language ro --keywords phrases-ro.txt --out vol-ro.json
```

Один запрос — до 1 000 фраз, стоит меньше доллара (цена — на сайте
DataForSEO в день замера; трата — решение владельца). Коды мест: Румыния
2642, Венгрия 2348, Болгария 2100. Ключ — только в окружении или в файле,
который не идёт в git; в чат и в репозиторий — никогда. Без ключа скрипт
выходит с понятной ошибкой, а бриф держит `origin: AC`.

## Импорт готовой выгрузки

```sh
node <seo-content>/scripts/import-market.mjs \
  --input <закрытая-выгрузка.json> --country BG --language bg \
  --source-ref <идентификатор-исследования> \
  --output <закрытая-папка>/market-bg.json
```

Формат HempScale: `country`, `language`, `import.demand`,
`import.questions`, `import.serpSnapshots`; нужен хотя бы один непустой
раздел. Несовпадение страны и языка, кривые числа, пустой экспорт —
ошибка. Существующий файл не перезаписывается. `people_also_ask` и
вопросные подсказки — источники вопросов; `people_also_search` — соседние
запросы, не готовый FAQ.

## Слово рынка и ловушки

- **Слово рынка против слова каталога.** H1 и title берут то, что набирают:
  `ulei cbd` (не «Uleiuri CBD»), `jeleuri cbd` (не «Produse comestibile»),
  `crema cbd` / `unguent cbd` (не «Produse topice»), `cbd olaj`,
  `cbd gumicukor`, `cbd krém` (не «Ehető», «Külsőleges»). Народный синоним
  рядом в скобках — приём лидеров выдачи: «Ulei CBD (ulei de canabis)».
- **Ловушка-синоним** — фраза о другом товаре: `ulei de cânepă`,
  `kenderolaj`, «конопено масло» — масло из семян, без значимого CBD.
  Ставится только в вопрос FAQ с объяснением разницы, не в H1.
- **Диакритика.** Набирают без неё (`ulei de canepa`, `caini`, `pret`);
  пишем с ней (`cânepă`, `câini`, `preț`) — Google сводит формы.
- **Чего не адресовать продающей страницей:** болезни, дети, беременность
  (`ulei cbd copii`, `cbd anxietate`, `cbd pentru dureri`). Это вопросы
  статьи или блока «что мы не обещаем» — [compliance.md](compliance.md).

## Что известно о рынках (на 08.10.2026)

**Румыния, ro.** Голова `ulei cbd` ≈ 2 400 в месяц (DataForSEO, 09.2026);
`ulei cbd pentru somn` ≈ 10 — «CBD + состояние» почти не ищут. Подсказки:
`ulei de canabis` — отдельная голова; хвосты `pret`, `pareri`, `farmacie`,
`dr max`, `catena`, `emag`, `1000 mg`, `full spectrum`, `caini`, `pisici`,
`legal in romania`, `test antidrog`. Выдача: по `% ` — карточки товаров
(10 из 10), по спектру, форме и животным — полки, по сну и тревоге —
статьи, по праву — гиды магазинов. Сильные соседи — аптеки (Farmacia Tei,
Dr. Max, Catena) и eMAG.

**Румыния, hu** (Трансильвания) и **Венгрия.** `cbd olaj`,
`kannabisz olaj`, `cbd kapszula`, `cbd gumicukor`, `cbd krém`,
`cbd balzsam`, `cbd olaj kutyáknak`; у лидеров обращение на «te». Надзор
NKFH 24.07.2026 прямо назвал недопустимыми «alvást támogató» и
обезболивание.

**Румыния, en.** Своего спроса мало, конкуренции почти нет: `cbd shop
romania`, `cbd oil romania`, `is cbd legal in romania`. Общие `cbd for
dogs`, `cbd cream` — иностранный интент, не целить.

**Болгария, bg** (DataForSEO, 02.09.2026): масла 47 % спроса, наружное для
суставов 16 %, капсулы 11 %; народное «канабис ойл» сильнее «cbd»;
крепость и спектр словами почти не ищут; в выдаче статьи и карточки,
аптеки — четверть.

## Свежесть

Дата частоты, дата выдачи и дата правового вывода — три разные даты.
Скачать старый файл сегодня — не обновить исследование. Досье
пересматривается по Search Console через 2–3 месяца после запуска
([measure.md](measure.md)).
