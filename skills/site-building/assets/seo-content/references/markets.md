# Исследование рынка для текста

## Минимальный вход

Нужны страна и язык отдельно (`RO/ro`, `BG/bg`, `IT/it`), аудитория B2C/B2B,
категория продукта и режим торговли. Для измерений сохранять поставщика,
дату и способ сбора. Для выдачи — запрос, регион, язык, устройство и дату.
Снимок другой страны или язык интерфейса не становится локальным спросом.

Различать `measured` / `bought`, `derived` и `assumed`. Пустой результат после
сбора, отсутствие сбора и ошибка доступа — разные состояния. Частотность `0`
не заменять на «нет данных»; она также не доказывает полное отсутствие спроса.
`null` не превращать в ноль. Данные Ads могут объединять близкие формулировки.
Поле рекламной конкуренции не подписывать KD.

## Источники HempScale

Их точные ревизии и пути — в [реестре](../assets/market-sources.json).
Читать доступный оригинал или выгрузку нужного рынка. В доступном снимке:

- **BG/bg:** подробный измеренный рынок, словарь, вопросы и снимки выдачи.
  Есть legacy-отчёты и `BG-bg.json`; даты внутри строк важнее даты скачивания.
- **RO/ro:** отдельная измеренная выгрузка в просмотренном GitHub-снимке не
  найдена. Данные рабочего раздела «Рынки» могут существовать отдельно.
  До получения экспортированного рынка черновые фразы остаются гипотезами.
- **IT/it:** найден обзор рынка и исторический замер спроса, но не полный
  экспорт запросов/выдачи для страницы. Правовую часть перепроверять перед
  коммерческим текстом; не объявлять торговлю разрешённой по одному обзору.

HempScale хранит новые рынки в базе. Его `scripts/market-export.mjs CC lang`
выгружает уже собранные данные в JSON; не запускает новый платный сбор.
Экспорт выполняется там, где есть штатный доступ к базе. При отсутствии
выгрузки запросить её расположение и продолжать независимую работу с брифом.
Наличие seeds для языка не означает, что его рынок измерен.

Нормализация полученной выгрузки этим навыком:

```sh
node <seo-content>/scripts/import-market.mjs \
  --input <закрытая-выгрузка.json> --country BG --language bg \
  --source-ref <ссылка-или-идентификатор-исследования> \
  --output <закрытая-папка>/market-bg.json
```

Принимается формат HempScale с `country`, `language`, `import.demand`,
`import.questions`, `import.serpSnapshots`; требуется хотя бы один непустой
раздел. Несовпадение страны/языка, некорректные числа и пустой экспорт вызывают
ошибку. Существующий файл не перезаписывается. Импортёр не ходит в сеть,
не кластеризует автоматически и не объявляет текст пригодным к публикации.
Его результат — вход для брифа, а не готовая карта страниц.

## Выбор запроса и страницы

1. Отфильтровать нерелевантное ассортименту. «Масло» может означать пищевое,
   моторное или косметическое; hemp seed oil и CBD extract — разные сущности.
   Чужой бренд, заболевание, промышленная конопля и товар для животных требуют
   отдельной оценки, не становятся нашими категориями автоматически.
2. Сверить типы страниц в выдаче группы: категории, карточки, статьи,
   маркетплейсы. Формат определять по локальной выдаче, а не слову «купить».
3. Сравнить пересечение URL. Порог «3 общих URL в топ-10» — рабочая эвристика
   HempScale, не требование Google. Смешанная выдача и широкие запросы требуют
   редакционного решения; не склеивать все запросы транзитивной цепочкой.
4. Составить карту: кластер → основной URL → назначение → соседние страницы.
   Проверить существующую страницу до создания новой. Фасет открывать для
   индексации по реальному ассортименту, спросу и контракту canonical сайта.
5. Перенести полезные вопросы в соответствующую страницу. `people_also_ask`
   и вопросные autocomplete — источники вопросов; `people_also_search` и
   related searches — соседние запросы, не готовый FAQ. Legacy-список с
   неизвестным происхождением проверить редактором, не переименовывать в PAA.

В брифе оставить исходную формулировку и её происхождение рядом с редакционной
версией вопроса. Для опасной или нерелевантной темы записать причину исключения.
Изменение интента при безопасной переформулировке должно быть заметно.

## Свежесть и следующий замер

Дата проверки законодательства, дата выдачи и дата частотности — отдельные.
Скачивание старого файла сегодня не обновляет исследования. Перед новым платным
сбором использовать имеющийся кэш и полномочия пользователя; не тратить API
кредиты автоматически. После запуска сайта пересматривать карту по Search
Console: реальные запросы, страницы, CTR, конверсии и конкуренция наших URL.
